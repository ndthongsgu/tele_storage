Telegram API Documentation

Stateless HTTP REST API for uploading, streaming, and managing files via Telegram Bot API

Overview

TeleStorage provides a lightweight, stateless HTTP API wrapper around Telegram's Bot API. It allows uploading any document up to 50MB directly to your Telegram chat/channel, and retrieving streamable direct download URLs using Telegram file_ids.

Zero Database Completely stateless architecture. No local database or disk storage required.
Direct Streaming Files are dynamically fetched and streamed directly from Telegram servers to the client.

Configuration (.env) & Telegram Setup Guide

Before making API requests, configure your .env file with your Telegram Bot Token and Chat ID:

TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHAT_ID=-1001234567890
PORT=8080
MAX_UPLOAD_SIZE_MB=50
Step 1

Cách lấy TELEGRAM_BOT_TOKEN

  1. Mở ứng dụng Telegram, tìm kiếm @BotFather (bot chính thức của Telegram có tích xanh).
  2. Gửi lệnh /newbot cho BotFather.
  3. Nhập tên hiển thị cho Bot (ví dụ: My Storage Bot).
  4. Nhập tên username cho Bot (bắt buộc kết thúc bằng bot, ví dụ: my_tele_storage_bot).
  5. BotFather sẽ gửi lại đoạn **HTTP API Access Token** (dạng: 123456789:ABCdefGhIJK...). Đặt chuỗi này vào TELEGRAM_BOT_TOKEN.
Step 2

Cách lấy TELEGRAM_CHAT_ID

  1. Tạo một Group (Nhóm) hoặc Channel (Kênh) mới trên Telegram (hoặc dùng nhóm sẵn có).
  2. Thêm Bot bạn vừa tạo ở Step 1 vào Kênh/Nhóm và cấp quyền **Administrator** (Quản trị viên) để Bot có quyền đăng bài/file.
  3. Gửi 1 tin nhắn bất kỳ vào Kênh/Nhóm đó.
  4. Lấy **Chat ID** theo 1 trong các cách sau:
    • Cách 1 (Dùng Bot Telegram): Forward (Chuyển tiếp) tin nhắn trong Kênh đó sang @userinfobot hoặc @GetIDBot hoặc @raw_data_bot. Bot sẽ phản hồi ID của Kênh (thường bắt đầu bằng -100...).
    • Cách 2 (Telegram Web): Mở Telegram Web (web.telegram.org), bấm vào Kênh của bạn. Thanh địa chỉ URL sẽ dạng .../c/1234567890/15 -> Chat ID sẽ là -1001234567890.
    • Cách 3 (Dùng Browser API): Truy cập link https://api.telegram.org/bot<BOT_TOKEN>/getUpdates trên trình duyệt để xem JSON chứa "chat":{"id": -100xxxxxxxxxx}.
POST /api/upload Upload File to Telegram

Request Format

Content-Type: multipart/form-data

Field Type Required Description
file Binary File Required File stream to upload (Max limit: 50MB)

Response Structure

{
  "status": "success",
  "data": {
    "file_id": "AgACAgIA...",       // Telegram file_id (use for download)
    "file_unique_id": "AQAD...",// Unique telegram file identifier
    "message_id": 1234,         // Telegram channel message_id
    "file_name": "report.pdf",  // Original file name
    "file_size": 1048576,       // Size in bytes
    "mime_type": "application/pdf",
    "download_url": "/api/download?file_id=AgACAgIA...&file_name=report.pdf"
  }
}

GET /api/download Stream / Download File

Query Parameters

Parameter Type Required Description
file_id string Required Telegram file_id returned during upload
file_name string Optional Custom filename for Content-Disposition header
dl integer Optional Set to 1 for attachment download, 0 for inline preview

Response

Direct HTTP Binary Stream with appropriate Content-Type and Content-Disposition headers.
